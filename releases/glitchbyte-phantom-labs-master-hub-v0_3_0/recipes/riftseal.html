RIFTSEAL Evidence Recipes

Quick and repeatable local file fingerprints, starting with the exact RIFTSEAL launcher syntax from your successful terminal output.

✦ Start here⚡ Domain recipes⛓ Integration🔐 Evidence▤ Reports⌨ Linux shortcuts
Command provenance: Your earlier Debian terminal output demonstrated the RIFTSEAL Python command and SHA-256 result. The RIFTSEAL source package was not included in this hub, so the command below is based on your successful example, not a fresh source-code test.
EASY · LOCAL

Fingerprint a file with RIFTSEAL

Replace your-file.zip with the real file you selected. Reads locally, no direct external query.
python3 -B \
  "$HOME/PhantomLabsLaunchers/riftseal-evidence-forge-2026/riftseal_evidence_forge.py" \
  --file "$HOME/Downloads/your-file.zip" --color always
EASY · BUILT IN

Verify a local SHA-256 yourself

Works without RIFTSEAL on normal Debian GNU/Linux. No network.
sha256sum "$HOME/Downloads/your-file.zip"
EASY · BUILT IN

See size and SHA-256

Useful for a personal verification record. Terminal only unless you choose to save it.
stat -c 'Bytes: %s' "$HOME/Downloads/your-file.zip" && \
sha256sum "$HOME/Downloads/your-file.zip"
Evidence hygiene: Keep your original evidence files unchanged; use hashes for integrity comparison. A matching hash supports byte-for-byte identity, not truth of the file's claims.
