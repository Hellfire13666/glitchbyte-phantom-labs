What the command ingredients mean

Here's your chemical makeup cheat sheet.

FlagWhat it means
python3 -BRun without generating Python .pyc cache files.
--color alwaysShow the colored terminal readout.
domain facebook.comCheck a public domain using fixed third-party data providers.
--liveExplicitly permit public-provider HTTPS requests.
--providers ...Select which documented sources to query.
--view fullPrint all gathered findings and provenance; it does not create additional findings.
--limit 200Allow up to 200 observations per provider.
--timeout 4Maximum seconds allowed for each public provider request.
--delay 1Pause one second between provider operations.
--out PATHSave a NEW private JSON file; existing files are never overwritten.
Public certificate names and historical records do not prove an endpoint is live, nor establish identity or wrongdoing. Never use these observations as permission to probe systems or access private accounts. Your 118 findings are a saved 2026 test snapshot, not a promise of the next scan's result.
