Linux Navigation Rescue

Commands worth keeping close to your keyboard. Built for the Debian Trixie machine you actually use.

✦ Start here⚡ Domain recipes⛓ Integration🔐 Evidence▤ Reports⌨ Linux shortcuts
EVERY DAY

Where am I?

Print your current working directory.
pwd
EVERY DAY

Go to the launcher workshop

Move to the folder containing your independently installed tool directories.
cd "$HOME/PhantomLabsLaunchers" && pwd && ls -1
EVERY DAY

List every installed HTML page

Find local pages even if you have forgotten their folder name.
find "$HOME/PhantomLabsLaunchers" -maxdepth 3 \
  -type f -name '*.html' -print
ONE-CLICK

Open the Master Hub

Refresh installed page links and then open Firefox through your default browser.
bash "$HOME/PhantomLabsLaunchers/glitchbyte-phantom-labs-master-hub-v0_2_0/START_HUB.sh"
ONE-CLICK

Open existing HEXBAZAAR shop

The shop's Rosie main HTML page, if that specific package has been installed.
xdg-open "$HOME/PhantomLabsLaunchers/hexbazaar-savage-intel-shop-v0_1_2_rc1_rosie_facebook_recipes/index.html"
CHECK · LOCAL

Verify the ZIP without extracting

Use both downloaded files. Stop immediately if checksum fails.
cd "$HOME/Downloads" && \
sha256sum -c hexbazaar-savage-intel-shop-v0.1.2-rc1-rosie-facebook-recipes.sha256 && \
unzip -tq hexbazaar-savage-intel-shop-v0.1.2-rc1-rosie-facebook-recipes.zip
