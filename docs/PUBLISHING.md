# Publishing checklist

1. Create a **private** GitHub repository named `glitchbyte-phantom-labs` under the account you control.
2. Extract the archive and review all source files for personal information, credentials, and unexpected behavior.
3. Upload the folder to the private repository or use `git init`, `git add .`, `git commit -m "Initial Phantom Labs archive"`, `git branch -M main`, and `git remote add origin <YOUR_REPO_URL>` followed by `git push -u origin main`.
4. Keep a second offline backup. GitHub is not a substitute for a backup.
5. Before making public, test the tools, inspect licensing of all assets, and select a clear software license if you want others to reuse the code.
6. Consider a GitHub Pages catalog after publication.
