# 🌹 OFFICIAL ROSIE // VISUAL STANDARD

This official repository rebuild uses the **approved RosieGlitchbyte character**, not a random cyberpunk character.

## Canonical visual anchors

- **Brown eyes** when visible
- **Long black / dark hair with electric-blue highlights**
- Established Rosie facial features from user-supplied special face references
- Anonymous/Anonymiss half-mask and unmasked Rosie are distinct approved variants
- Character should be small or blended into the tool theme when the layout is information-heavy
- Rotate dark, hot pink, cyan, ultraviolet, acid lime and other glitch palettes. Avoid repeating the same theme in every future project
- Never invent an unfamiliar Rosie substitute just to fill artwork space

## Approved assets and publishing

The approved Rosie opening artwork has been uploaded to the existing repository at:

[`artwork/labface2.png`](../artwork/labface2.png)

The homepage now embeds this exact file using:

```markdown
![Official RosieGlitchbyte Phantom Labs hero artwork](artwork/labface2.png)
```

Keep the source filename intact to preserve the upload and Git history. Do not replace this with a generic Rosie character or rename it without also updating the README link.

Original artwork should be credited appropriately and follow the existing [license notice](../LICENSE-NOTICE.md).

## Design language

GitHub Markdown supports links, tables, images, and code samples; it does **not** turn screenshots of buttons into working controls. The home page must always contain real clickable Markdown links to the repository's actual files.

A separate GitHub Pages website could provide an interactive searchable gallery in a future build. That would be an independently reviewed change, not implied by this README design.
