What is actually included in the v2 workflow?

1Python conversion core: glitchbyte_art_new_only_v2.py creates optimized WebP copies of new images and remembers completed ones in a separate local history file.

FUTURE INSTALL · ONLY IF YOU CHOOSE

First-time Debian-based Linux setup

  1. Get the actual source folder from the official GitHub repository, via clone or Code → Download ZIP.
  2. Open a terminal inside the extracted tools/glitchbyte-art-vault-converter directory. Do not use your Alwaysdata server.
  3. If Pillow is missing, run the optional dependency command below.
  4. Only if v2 is not installed already, run the installer once.
sudo apt install python3-pil
bash INSTALL_NEW_ONLY_v2.sh

Those commands work only on a system with the required tools and when the second command is executed inside the v2 source folder containing the installer and Python script.

EVERYDAY USE · OFFLINE

Art in · WebP copies out

1Place new pictures in ~/Desktop/GlitchByte-To-Upload.
2Double-click your existing GlitchByte Art Vault Converter desktop shortcut and choose Execute / Launch in Terminal if prompted.
3Find smaller WebP copies in ~/Desktop/GlitchByte-Upload-Ready.
4Upload only the converted copies to the Hangout Art Vault yourself.

The tool never posts to Facebook, never uploads your originals, and never edits your Hangout website.

OPTIONAL TERMINAL RECIPE · REAL V2 FLAGS

Run the new-only converter directly

While inside the real v2 source directory, if you prefer terminal use instead of a desktop shortcut:

python3 glitchbyte_art_new_only_v2.py \
  --source "$HOME/Desktop/GlitchByte-To-Upload" \
  --dest "$HOME/Desktop/GlitchByte-Upload-Ready"

On first-time installation, v2 intentionally records images already sitting in the input folder as handled without processing them. New pictures placed there afterward are converted; originals are untouched, and previously processed pictures are not regenerated simply because you delete output copies.

History safety: History normally lives in ~/.local/state/glitchbyte-phantom-labs/art-vault-new-only-v2-history.json. Do not delete it unless you deliberately want to reset the tracking.
