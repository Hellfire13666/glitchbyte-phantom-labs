WHAT THIS RESOURCE ACTUALLY DOES

Repair and refresh a Facebook / Messenger link preview

The Sharing Debugger reads publicly accessible page metadata, reports Open Graph warnings and requests a new scrape of a URL. It does not shrink image files, install software, change your website settings, or automatically repair HTML.

Official tool: https://developers.facebook.com/tools/debug/
BEGINNER RECIPE

Four real steps

1Open the official Sharing Debugger.
2Paste the exact public page URL you want people to share, then press Debug.
3Review the Link Preview, warnings and Open Graph fields.
4If the website’s actual metadata was corrected, click Scrape Again to request a refreshed preview.
GLITCHBYTE HANGOUT REFERENCE

Check these exact fields

  • og:url · canonical public Hangout URL
  • og:title · intended shared title
  • og:description · short preview description
  • og:image · publicly reachable approved share image URL

Compare the actual preview with the approved eight-door Hangout poster; do not replace the approved share art.
