## 🧪 Try a mini lab session

For a safe, offline-oriented introduction, inspect commands before running them:

```bash
git clone https://github.com/Hellfire13666/glitchbyte-phantom-labs.git
cd glitchbyte-phantom-labs
python3 tools/glitchbyte_log_constellation.py --help
```

For the **Go project**:

```bash
cd tools/go/voidlantern-go
go test ./...
go vet ./...
go build -o voidlantern .
./voidlantern -url https://example.com -out reports/example.json
```

### 🗃️ Where do reports land?

Every project may use different report paths. From your current working directory:

```bash
find . -type f \( -name "*.html" -o -name "*.json" -o -name "*.csv" \)
```

For guidance on report output, full setup and troubleshooting, see the [Tool Starter Guide](TOOL_STARTER_GUIDE.md).
