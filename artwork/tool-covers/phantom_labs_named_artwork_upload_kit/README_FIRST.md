# GlitchByte Phantom Labs artwork upload kit

This kit holds **11 exact named-tool matches** at full PNG resolution. It does NOT include alternate covers; those belong to the separate user-choice board.

1. Unzip this kit.
2. Open your [Phantom Labs HQ artwork upload door](https://github.com/Hellfire13666/glitchbyte-phantom-labs/upload/main/artwork/tool-covers).
3. Upload the 11 image files from `artwork/tool-covers/` keeping their exact filenames.
4. Commit the upload. GitHub workflow `tool-cover-linker.yml` updates matching tool showcase pages automatically when files are present.
5. Check the [tool vault](https://github.com/Hellfire13666/glitchbyte-phantom-labs/blob/main/docs/TOOL_VAULT.md).

The original Rosie Phantom Scan V2 image and IP Shadow Scraper image are already linked. Tools with multiple artwork choices are intentionally excluded until you decide.

Only upload public-approved cover artwork. Avoid private reports and credentials.
